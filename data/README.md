Built data for the viewer. Regenerate with `make sf` from the repo root.

- `sf-land.json` — modern land polygon (TIGER 2024), public domain
- `sample-buildings.geojson` — Phase 0 test fixture
- `sf-buildings.bin.gz` — SF buildings (BAYT columnar format, see viewer/src/data/columnar.ts). ODbL 1.0: © OpenStreetMap contributors, Overture Maps Foundation; DataSF (PDDL)
- `sf-trees.bin.gz` — SF street trees (DataSF, PDDL)
- `fire-1906.json` — 1906 burned area (data/manual research)
